# Investigação Rposty / Instagram

Comece pelo [relatório](RELATORIO.md), que descreve o mecanismo recuperado e a comparação com o Devwolf Downloader.

- [Metodologia e reprodução](METODOLOGIA.md)
- [Índice de evidências](EVIDENCIAS.md)
- `evidence/`: JSONs completos REA, inventários e reprodução de erro.
- `sources/`: seleção de fontes decompiladas usadas como evidência auxiliar; não integrar ao código de produção.
- `scripts/`: exportador JADX e verificação do contrato de erros.
- `integridade.json`: hashes dos arquivos entregues e identificação do APK.

Escopo: análise estática do APK fornecido e leitura do projeto. Não comprova downloads atuais. Código de produção preservado; documentação criada separadamente conforme solicitado.
